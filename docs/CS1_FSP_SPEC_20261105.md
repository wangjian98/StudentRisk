## 1 · 使用方法

### 1.1 谁在什么时候用它

| 场景 | 输入 | 输出 | 人工成本 |
|---|---|---|---|
| **新段/新学期开课第一天**（主场景） | 该段全体有 IDE 行为的学生（≥150 人）+ 老师确认的 **8–16 个案例** | 段级风险分排序 + top-k 干预名单 + 段内定位 + 拒答标记 | 老师看 8–16 份名单，每份约 1 分钟 |
| **段中滚动**（每新增 20 个标注） | 同段累计标注 | 刷新风险分与名单 | 同上，增量 |
| **学期末结果复盘** | 全学期累积标签 | course 级挂科风险（早期预警通道，见提案 §8） | 无（内部） |
| **老师/班主任侧** | 名单 + 卡点证据 | "在第 2 段第 7 题卡住：只改不跑 + 焦点碎片化"的可照读建议 | 0（自动生成） |

### 1.2 单次使用流程（8 步）

```
①  取该段全部学生的 IDE 行为聚合（agg10：7 类事件计数/总事件/触达题数/时间跨度）
②  段锚定转导标准化：对该段**全部无标签行**算中位数/MAD，标准化 9 维绝对量特征
     —— 只用无标签行，不含任何标签
③  算同伴相对 10 维：peer_z = (本人该段 agg10 − 该段中位数) / 该段 MAD，clip 到 ±5
     （教师端本来就有同班/同段的行为数据；不需要学生个人历史）
④  取老师确认的 K 个案例（K 个掉队 + K 个未掉队）作为支撑集
⑤  按 K 选判别器并拟合：
       K=1,2 → 逻辑回归，特征只用 peer_z_submit 这一维
       K≥4   → 随机森林（100–300 树），特征用同伴相对 10 维（K≥8 可加全部 29 维）
⑥  打分：该段其余全部学生 → 风险分排序
⑦  校准：套用交叉拟合 Platt 映射（历史段上拟合）→ 概率可定阈值
⑧  拒答判定 + 输出：
       K<2 或该段无标签样本<100 → 只输出"证据不足"，不给分数
       K≤4 → 给分但标"低置信"，附 bootstrap 分数区间
       命中名单再走 IPSD 截断（截到第 3 题）→ 风险曲线 + 首次越阈题号 → 逐题同伴对照 → 卡点证据
```

### 1.3 退化与兜底

| 情况 | 处理 |
|---|---|
| 该段无标签样本 <100 | 转导不可靠 → 拒答；退化为"段基线 + 全局先验"，只报相对位置不报概率 |
| K<2 | 拒答 |
| K=2~4 | 给分 + 低置信标记 + bootstrap 区间（重复抽支撑集 B=50 次） |
| 老师不愿标注 | 允许只标"明显掉队"（正例），此时用"单类 + 密度比"退化模型（精度未测，产品上不建议） |
| 新题型/新课程（跨段） | 不用原型迁移（实测仅 0.60–0.67）；走"全标签训练 + 段锚定标准化"，跨段 pooled 0.9184 |

### 1.4 交付物形态（老师看到什么）

```
【本段风险名单 · 8 个标注案例校准】
排名 学生  风险   首次越阈题号  卡点证据                        建议动作
1    #311  0.99   第 3 题       第7题 776编辑/47运行；焦点54/h   "先跑起来看报错再改"；15分钟1:1
...
覆盖说明：本段 388 人，名单 19 人（top5%），基准率 10.6% → 精确率约 0.68
置信度：低置信（K=8，支撑集小）｜分数区间 0.86–0.91
```

## 2 · 训练过程

### 2.1 标签与数据的构造（离线，一次性）

| 步骤 | 做法 | 产出 |
|---|---|---|
| T1 事件聚合 | IDE_logs.csv（2858.8 万行）按 (学生, part, exercise) 聚合 7 类事件计数 + 总量 + 首末时间戳 + timeToDeadline | 习题级表 44,764 行 |
| T2 阶段级聚合 | 按 (学生, part) 聚合 → **agg10** = [ins, rem, pas, fg, fl, run, sub, total, distinct_ex, span_h]；序列取最近 128 事件 | **stage_dataset.npz**（2171 行） |
| T3 标签（drop） | `drop=1 ⇔ 该 (学生,part) 是他到达过的最远段，且从未到达 part7` | 258 个正例（11.9%） |
| T3' 标签（final） | `passed.csv` 的课程级 failed，按学生广播 | 314 名挂科（66.4%） |
| T4 分组折 | 按**学生**分组 5 折 × 3 seeds（42/123/777），课程级标签分层；**同伴统计量只用训练折** | 评估协议（防泄漏） |

> **标签的关键性质**：drop 依赖"**此后不再出现**"这一未来事实 → 训练时是**目标**，推理时不可得；这正是需要预测的部分（提案 §8）。

### 2.2 特征构造（确定性、无参数、线上线下同一条代码）

| 族 | 维度 | 公式 | 依赖标签？ |
|---|---:|---|---|
| A 强度 | 4 | log1p(total)、log1p(distinct_ex)、log1p(span_h)、log1p(total/span) | 否 |
| B 比率 | 3 | rem/ins、focus_lost/span、run/max(total,1) | 否 |
| C 进度 | 2 | distinct_ex / 该段题量基准、该生第几段 | 否 |
| **peer 同伴相对** | 10 | 对 agg10 每维：(本人 − 该段中位数) / 该段 MAD，clip ±5 | 否（**段内相对**，用该段无标签行即可算） |
| self 自参照 | 10 | (本人该段 − 该生此前各段均值) / 标准差；首段为 0 | 否（但**冷启动时不可得** → 主通道不用） |

**段锚定转导标准化（M1）**：A/B/C 这 9 维是**绝对量**，跨段会漂移。做法：对段 p，用该段**所有行**（含待预测学生，不含标签）算中位数/MAD，再标准化：

```
for each part p:
    med_p, mad_p = median(agg_derived[p]), MAD(agg_derived[p])      # 只用无标签行
    Z9[p] = (abs9[p] - med_p) / mad_p
```

peer10 本身就是段内 MAD-z，**不再二次标准化**；self10 是学生内 z-score，天然可比。

### 2.3 少样本拟合（"训练"= 每段一次轻量拟合）

```
输入：段 p 的样本矩阵 X_p（= Z9_p ⊕ peer10_p，可选 self10）、支撑集索引 sp/sn（各 K 个）
if K <= 2:
    model = LogisticRegression(max_iter=2000, C=1.0, class_weight='balanced')
    model.fit(X_p[sp ∪ sn][:, peer_submit 列], y[sp ∪ sn])
else:
    model = RandomForestClassifier(n_estimators=300, min_samples_leaf=2,
                                    max_features='sqrt', class_weight='balanced',
                                    random_state=42)          # K 少时用 100 树 / 1 seed 即可
    model.fit(X_p[sp ∪ sn], y[sp ∪ sn])
scores = model.predict_proba(X_p[其余行])[:, 1]
```

- **无离线预训练**：模型在每个新段现场拟合，几百样本、毫秒级；冷启动不需要历史标签。
- **为什么可以现场训**：段级任务的监督信号就是"这一段他是否停住"，K=8 已有 94% 的上限效果（实测 0.875 vs 0.929）。
- **不使用**：伪标签自训练（图传播+RF、原型+RF 实测全线更差）、深度骨干（判别线输 0.03–0.13，且度量学习随 K 变差）、跨段原型迁移（0.60–0.67）。

### 2.4 校准（离线拟合一次，线上套用）

```
离线（在历史段上）：
  1) 用段级全标签模型做 OOF 分数（按学生分组 5 折）
  2) 对 logit(p) 与 y 做 logistic 回归 → a·logit(p) + b   ← 交叉拟合 Platt
  3) 校验 ECE / Brier
线上：new_score = sigmoid(a·logit(p_new) + b)
实测：ECE 0.0677 → 0.0134；Brier 0.0493 → 0.0408；AURC 0.660
```

- 为什么必须做：原始分数**过度离散且系统性高估**（斜率 1.271 / 截距 −0.799）→ 直接定阈值会误报。
- 少样本场景更要校准：K 越小方差越大（重复间 std 0.03–0.06）。

### 2.5 拒答（不是"置信度低就闭嘴"，而是有明确触发条件）

| 触发条件 | 动作 | 依据 |
|---|---|---|
| K < 2 | 输出"证据不足" | K=1 的最好配置 0.791（85%），方差大 |
| 段内无标签样本 < 100 | 拒答或退化为段基线 | 转导统计量不稳 |
| K ≤ 4 | 给分 + "低置信"标记 + bootstrap 区间（B=50） | 重复间 std 0.03–0.06 |
| （可选）正负原型分离度过低 | 拒答 | 支撑集不代表整体时原型不可靠 |

### 2.6 评估协议（验收怎么算）

| 指标 | 口径 | 目标值 |
|---|---|---|
| 学习曲线 | 段内冷启动，K∈{1,2,4,8,16}，12 次重复，part 内 pooled AUC | K=8 ≥ 0.87；K=16 ≥ 0.89（上限的 ≥94%） |
| 弱段 | part5/part6 的 pooled | ≥ 0.87（实测 0.873） |
| 稀有类 | 完课仍挂科学生级 AUC | K=16 ≥ 0.74（实测 0.749） |
| 校准 | ECE（10 桶）/ Brier | ECE ≤ 0.02（实测 0.0134） |
| 跨段 | 跨段全标签 pooled | ≥ 0.91（实测 0.9184） |
| 早警 | IPSD 前 3 题 top5% 精确率 | ≥ 0.65（实测 0.679） |
| 拒答 | K<2 时的拒答率 | 100% |
| 显著性 | 重复级配对 bootstrap 2000 次 | K=16 与全标签的 Δ ≤ 0.04（实测 −0.0324） |

### 2.7 监控与再训练

| 触发 | 动作 |
|---|---|
| 新段开课 | 收集 8–16 个标注 → 拟合 → 冻结 → 出名单 |
| 段内累计新增 20 个标注 | 重拟合 + 重排名单（滚动） |
| 每学期结束 | 用累积标签重拟合 Platt 校准器；重算 ECE/学习曲线，确认未漂移 |
| 监控指标 | 每段 AUC、覆盖率（拒答率）、top-k 精确率、分数分布与校准曲线、支撑集与整体分布的距离 |
| 异常处置 | 若某段 top-k 精确率 < 0.5（基准率的 5×），检查：标注质量 / 该段是否异质 / 特征是否需重算 |

## 4 · 端到端实例（新开第 2 段，标注 8 个案例）

| 步 | 输入 | 处理 | 输出 |
|---|---|---|---|
| 1 | 该段 388 名学生的 IDE 行为 | 聚合 agg10 | 388×10 矩阵 |
| 2 | 同上 | 段锚定转导标准化（该段自己的中位数/MAD） | Z9 |
| 3 | 同上 | peer_z（该段 MAD 归一） | peer10 |
| 4 | 老师确认 | 4 掉队 + 4 未掉队 | 支撑集 8 例 |
| 5 | 支撑集 | RF(100–300 树) 拟合 | 模型 |
| 6 | 其余 380 人 | 打分排序 | 风险分 |
| 7 | 风险分 | 交叉拟合 Platt | 概率（ECE 0.0134） |
| 8 | top5%（19 人） | IPSD 截断到第 3 题 + 逐题同伴对照 | 名单 + 卡点题 + 证据 + 建议 |
| 9 | 名单 | 覆盖率/精确率回写 | top5% 精确率 ≈0.68（基准率 6.4×） |

**降级路径**：若只标到 2 个 → 自动降到"单维 peer_z_submit + 逻辑回归"（0.856 = 上限 92.2%）并打低置信标记；<2 个 → 只输出"证据不足"。

## 5 · 上线清单（DoD）

- [ ] 特征构造器与评估脚本共用同一份代码（避免线上线下不一致）
- [ ] 支撑集抽样固定随机种子，可复现
- [ ] Platt 校准器版本化，每学期重拟合并记录 ECE
- [ ] 拒答规则在代码里显式实现（K<2、无标签样本<100）
- [ ] 名单输出带：精确率口径说明 + 覆盖人数 + 基准率 + 置信标记
- [ ] 每段留一份"该段 AUC/精确率"回写表，用于下一段判断是否需要改标签口径
- [ ] 提交质量标记（空提交/刷提交/秒提交，占 26.3% 分段行）作为**数据清洗前置**，不作为结论修正
