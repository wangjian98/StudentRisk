## 0 · 结论先行

1. **现有主模型（段级 rf29，主协议 pooled 0.9258 / 本次复现 0.9279）的问题不是"不够强"，是"不够对"**：
   概率没校准（ECE 0.0677、斜率 1.271、截距 −0.799）、右删失段被系统性高估（part7 平均预测 0.084）、
   "段内早警"里混进了本人此前各段的自参照（0.9129 → 纯净口径 0.8263）、
   输出只有段级单点风险（不定位、不拒答）、18.8% 走完全程仍挂科的终局画像只有 0.61、
   弱段（part5 正例 15 / part6 正例 22）缺标签、跨段/跨学期外推没有干净口径、外部数据集验证仍空。
2. **"少样本在 CS1 失败"是伪结论**：仓库里 4 个少样本实验的"少样本适配"是 **no-op**（内层 3 步梯度被丢弃）+ 段索引错位一位 + 单类别 query 造成 AUC=NaN；
   唯一协议干净的那条（旧 B-plan，深度骨干 + FiLM + participation 抽样）给 ROC≈0.537 且**对 K 无响应**——它测的是"深度 + FiLM + 错误抽样"，不是"少样本"。
   **少样本在这个项目上从来被正经检验过。**
3. **新模型 CS1-FSP（段锚定 + 少样本 + 拒答带）实测有效**：每段只给 K 个标注（正例 K + 负例 K），part 内 pooled AUC：

   | K（每段标注数） | 1 | 2 | 4 | 8 | 16 | 全标签上限 |
   |---|---:|---:|---:|---:|---:|---:|
   | **最优配置** | **0.791**<br><sub>peer_submit+logit</sub> | **0.856**<br><sub>peer_submit+logit</sub> | **0.854**<br><sub>peer_submit+logit</sub> | **0.875**<br><sub>all29+RF</sub> | **0.896**<br><sub>all29+RF</sub> | 0.929 |
   | 占上限 | 85.2% | 92.2% | 91.9% | 94.2% | **96.5%** | 100% |

   **弱段 part5/6 用 K=8 被救到 0.873**（此前是最弱两段）；**稀有子类"完课仍挂科"用 K=16 达全标签的 96.8%**（0.749 vs 0.774）。
4. **四条反直觉发现**（都推翻项目此前的"共识"，而且都能直接指导落地）：
   - **特征比模型重要**：K=2 时「只用 peer_z_submit 一个维度 + 逻辑回归」= **0.856** > 「29 维 + 逻辑回归」= 0.780（**+0.076**）→ 小标签预算下"少而准"胜过多而全。
   - **非线性要 K≥4 才划算**：K≤2 线性最好（0.791），K≥4 RF 最好（0.847→0.896）；浅树全区间最差（0.59–0.80）→ 交互在小样本下估不稳。
   - **伪标签自训练是负结果**：图传播+RF（0.835）、原型+RF（0.835）**全部低于各自基线**（0.857 / 0.845）→ 主模型**不用**自训练。
   - **深度度量学习无效且随 K 变差**：MLP+原型损失 K=1→0.716、K=2→0.686、K=4→0.650、K=8→0.608 → 旧 5-shot 失败该归因于**架构 + 实现**，不是"少样本"。
5. **段内"更早"有天花板代价**：整段全标签上限 0.929，只看第 1 次坐下降到 **0.782**（掉 0.147）；坐下列少样本 K=8 仍有 0.672（上限的 86%）。→ 产品不能同时承诺"更早"和"更准"。
6. **落地建议（3 条决策）**：
   - **A. 少样本用于"开新段/新学期第一天"**，不用于刷 in-distroduction 准确率。产品口径建议：**每个新段人工确认 8–16 个案例（正负各半），即可上线预警；K<4 一律拒答（输出"证据不足"），不给分数。**
   - **B. 模型规格定稿**：段锚定转导标准化 → 特征只用**同伴相对 10 维**（+ peer_z_submit 单独一条）→ K≤2 用逻辑回归、K≥4 用 RF → 交叉拟合 Platt 校准 → 拒答带。
   - **C. 别再投深度少样本**（元学习/度量学习/FoMAML）：在本数据集上已被 3 种实现 + 本次对照重复证伪；把人力放到"外部数据集验证"（投稿硬缺口）和"终局画像"上。

## 1 · 现有模型的不足（分层）

### 1.1 第一层：判别线上"换模型"已无收益（9 条实测证伪）

| 方向 | 实测（主协议 part 内 pooled AUC，基线 rf29 = 0.9258） |
|---|---|
| 换学习器（LGBM / HGB / 原型混合 MoE / 秩平均集成） | 0.9255 / 0.9191 / 0.9256 / 0.9268 —— 全都 ≤ 基线 |
| 加特征（全轨迹多尺度 14 维 / M4 强度 / 截止压力 9 维） | −0.0058 / −0.0013 / +0.0020（不显著） |
| 特征层残差化 | −0.027 |
| 直接优化主指标（LambdaRank，group=part） | −0.0229，P(Δ≤0)=99.05% |
| 序数深度回归（预测最终到第几段） | −0.0169，P=97.1% |
| 每段单独建模 | 0.9216 < 0.9258（收缩混合 κ=100 → 0.9276，噪声级） |
| 深度骨干判别线 | MetaMamba −0.1302；CS2-SPC 0.79 vs RF 0.87；CS2-FWD 0.82 vs RF 0.91（纯净口径后仍 −0.047） |
| 更细决策粒度 | 习题级 hazard 0.4920（低于随机，基准率 0.58% 不匹配） |
| 段内多尺度 / 会话结构特征 | 坐下级内 0.8644 vs 0.8665（无增量） |

> 归位框架（已成立）：**粒度—基准率—归纳偏置三律**。
> ① 决策单元粒度必须匹配事件基准率（可学区间 6–18%）；② "结构"的价值在**定义观测单位**不在提供特征；③ 主指标是评估口径不是训练目标。
> **本次新模型是这条三律在"标签预算"维度上的延伸：第四律 = 小标签预算下，先选特征、再选模型。**

### 1.2 第二层：模型的四个结构性缺陷（不是容量问题，是口径/形式问题）

**① 概率没校准 → 不能直接定阈值**
段级 RF：ECE(10 桶) **0.0677**、校准斜率 **1.271**、截距 **−0.799**、Brier 0.0493、AURC 0.660。
交叉拟合 Platt / 等渗重校准后 ECE → **0.0134**、Brier 0.0408（纯后处理）。
→ 含义：**能力其实已经在，只是"分数"不能直接当"概率"卖**。少样本更严重（K 越小方差越大），**必须自带拒答带**。

**② 右删失段被系统性高估**
part7（215 行，真实基准率 0）平均预测 **0.084**，其余段 0.14–0.30 → 模型把"删失段"也当风险段。

**③ 自参照泄漏 → 段内早警被高估**
CS2-FWD（段内"中途停下"早警）含自参照 0.9129 / 剔除自参照 **0.8263**（Δ −0.0866，P(Δ≤0)=0.0015）。
→ 所有"段内早警 0.91"的表述必须改口径；深度模型落后 RF 的幅度也从 −0.092 缩到 −0.047。

**④ 冷启动对同伴数据是硬依赖，对学生历史不是**
Layer-0 分解：去 10 维自参照（= 新学生冷启动）0.9208 vs 0.9258（Δ **−0.0050，不显著**）；
去 12 维同伴相对 0.8982（Δ **−0.0276，P=100%**）；只留本段 9 维 0.8733。
→ **冷启动只需要同伴数据（教师端本来就有），不需要学生个人历史** —— 这正是少样本/冷启动方案能落地的前提，也是 §3 里"peer 特征独占鳌头"的原因。

### 1.3 第三层：输出形式与覆盖面的缺口

| 缺口 | 实测 | 影响 |
|---|---|---|
| 只给段级单点风险，不定位、不拒答 | 81.8% 掉队发生在**段内中途**（该段完成比例中位 0.474） | 产品要"卡在哪一题/哪一次坐下"，模型给不出 |
| 终局画像弱 | 18.8% 走完全程 7 段仍挂科；该稀有子类全标签 RF 也只有 AUC **0.774**（本次实测） | 不能承诺"提前预测谁会挂科" |
| 弱段样本极少 | part5 n=250/正例 15（0.8511）、part6 n=236/正例 22 | 全项目最弱两段，标签预算最紧张 |
| 跨段/跨学期外推口径混乱 | 学生级 LOPO 是硬墙（ROC 0.61–0.64）；但**阶段级 RF 的跨段几乎不掉**：本次实测跨段全标签 RF pooled **0.9184**（vs 段内全标签 0.9289），仓库既有读数 0.9128（−0.013） | 结论应是"**LOPO 硬墙是学生级深度模型 + FiLM 的性质，不是阶段级任务性质**"（FiLM 把模型锁在 seen-part 表征上：part7 ROC 0.221 → 去 FiLM 0.701） |
| 外部数据集验证缺失 | 论文附录 B 唯一剩余高优缺口 | 核心主张只在一个 MOOC 上成立，投稿硬伤 |
| 提交质量污染 | 570/2171 行（26.3%）、260 名学生 | 已用等样本随机剔除对照验证**不驱动**主结论，但要写进边界 |

### 1.4 第四层：工程/口径层面的隐患（这次盘点挖出来的）

1. **旧 few-shot 评估脚本是坏的**（见 §2.1）→ 少样本这条线的历史结论不可信。
2. **`part_tot` 口径错**：坐下级脚本里 `part_tot[p] = par[par==p].max()` 得到的是段号本身（1..7），被当作"每段题量基准"；同时把 `timeToDeadline` 当成 span/n_ex 用 → 那个"坐下级 0.8665"里的"进度"特征其实是**截止压力**。本次新建的坐下级脚本按语义重写（`run_cs1_fs_sitting.py`）。
3. **pandas 时间戳 µs/ns 陷阱**（`astype('int64')` 会把时间缩小 1000 倍）已在 `build_student_seqs.py` 修掉，但重跑消融时仍需注意。

## 2 · 新模型提案：CS1-FSP（段锚定 + 少样本 + 拒答带）

### 2.1 为什么现在可以重提少样本（三条前提）

1. **旧证据不成立**：per-part 5-shot FOMAML 评估的适配后权重未被加载（`eval_per_part_5shot.py:67-84` 返回 pre-adaptation θ，等于没适配），
   跨 (part, seed) 迭代还会把已适配的权重带进下一段（状态泄漏，参数漂移 ~0.0088），
   `task_ids` 是 0-indexed 而脚本按 `range(1,8)` 遍历（**段索引错位一位，原始 part1 从未被评估**），
   headline "acc=1.0 / macroF1=1.0" 来自 `qry_n_passed=0` 的**单类别 query**（AUC=NaN）。
   → 唯一协议干净的 `eval_participation_kshot.py` 给 ROC≈0.537 且**对 K 无响应**。
   **"少样本失败"是伪结论；而且那条线的骨干（深度 + FiLM）本来就已被判别线证伪。**
2. **骨干选错了**：少样本若建在深度骨干上，必然被"深度在 CS1 判别线输 0.03–0.13"这条已证事实拖死。
   → 少样本主模型**不用深度骨干**（深度只做对照，见 §3.5）。
3. **少样本场景真实存在**：part5 正例 15、part6 正例 22；新学期/新学校/新课程开课 = 完全冷启动；
   稀有子类（完课仍挂科）全标签也只有 59 个正例。

### 2.2 机制（四件套）

| # | 机制 | 做什么 | 为什么（挂证据） |
|---|---|---|---|
| M1 | **段锚定转导标准化** | 每段的绝对量特征（A 强度 4 / B 比率 3 / C 进度 2）用**该段自己的**中位数/MAD 标准化（只用无标签行 → 合法转导）；同伴相对 10 维、自参照 10 维保持原样 | 段间分布漂移是跨段迁移的第一障碍；段锚定后跨段全标签 RF 达 pooled 0.9184（LOPO 硬墙消失） |
| M2 | **双原型距离比** | K 个掉队者 + K 个未掉队者 → 原型 c⁺/c⁻，score=(d⁻−d⁺)/(d⁻+d⁺) | 等价于**线性**判别方向，作为线性对照保留：它与 logit 打平 → 证明瓶颈是"线性 vs 非线性"，不是"原型 vs 判别" |
| M3 | **转导图传播（kNN 图）** | 以 K 个标注为种子，在段内无标签样本上做标签传播（k=15, α=0.9, 20 轮），用传播结果做排序/伪标签 | 每段有 236–471 行**无标签**样本，"少标签 + 多无标签"是少样本的标准解法 |
| M4 | **拒绝 + 校准** | 支撑集 K<4 或传播后种子一致率不足 → 输出"证据不足"；最终分数走交叉拟合 Platt（沿用已实测的 ECE 0.068→0.013 流程） | 主模型原始概率 ECE 0.0677、斜率 1.271；K 越小方差越大，**不校准就不该给阈值** |

> **最终模型规格（按 §3 实测定稿）**：
> 段锚定转导标准化 → 特征 = 同伴相对 10 维（K≤2 时只用 peer_z_submit 1 维）→ K≤2 用逻辑回归、K≥4 用 RF（100–300 树）→ 交叉拟合 Platt → 拒答带。
> **明确不用**：伪标签自训练、深度度量学习、跨段原型迁移（§3.4/§3.5 均为负结果）。

### 2.3 实验协议（全新，不与已有 5 折按学生分组协议混用）

- **FS-A 段内冷启动学习曲线**：每段只给 K 个掉队者 + K 个未掉队者（K=1/2/4/8/16），query = 该段其余行，12 次重复，指标 = part 内 pooled AUC
- **FS-B 弱段救援**：part5 / part6（正例 15 / 22）
- **FS-C 跨段迁移**：support 只来自其它段，测试目标段
- **FS-D 坐下级（段内更早）**：第 1 / 2 次坐下的截断特征
- **FS-E 稀有子类**：到达 part7 但最终挂科（59 人）对完课通过（156 人），学生级 AUC
- **参照系**：REF-global-main（主协议 RF，原始空间，**管线 sanity check**）、REF-inpart-full（段内全标签 RF，**与少样本同一特征空间**）、REF-crosspart（跨段全标签 RF）
- **显著性**：重复级配对 bootstrap 2000 次（按段重采样 + 按重复重采样）

### 2.4 模型族 × 特征集（实验真正要回答的问题：「小标签预算下哪种归纳偏置还站得住？」）

| 方法 | 归纳偏置 |
|---|---|
| proto | 线性（原型方向） |
| nn | 局部邻域（1-NN） |
| logit | 线性（对照） |
| tree2 / tree3 | 浅层交互规则（少量样本即可表达"提交少 且 编辑多"这类交互） |
| rf | 非线性集成（K 标签直接训练） |
| ls | kNN 图标签传播（转导） |
| ls_rf | 传播伪标签 → RF 重训 |
| proto_rf | 原型伪标签 → RF 重训 |
| metric | 度量学习原型网（MLP + 原型损失，纯对照） |

特征集：`all29`（全特征）/ `peer10`（只留同伴相对 10 维）/ `peer_submit`（**只留 peer_z_submit 1 维** —— 全项目 7 个段里的第 1 重要特征，0.057–0.127，第 2 名 0.007–0.024，领先一个数量级）。

**四个读数（每一条都直接改写落地方式）**

1. **曲线是单调上升的**：RF 从 K=2 的 0.740 升到 K=16 的 0.896；旧实验是"对 K 无响应"的平线（ROC 0.537）→ **旧失败源于实现/骨干/抽样，不是少样本本身**。

## 4 · 结论与落地路径

### 4.1 对"现有模型不足"的总判断

| 层次 | 判断 | 行动 |
|---|---|---|
| 模型容量 | **已封顶**（9 条实测证伪） | 停止换模型、停止加特征 |
| 概率输出 | **未校准**（ECE 0.068） | 上线前统一交叉拟合 Platt（已有实测路径，代价一行后处理） |
| 删失处理 | part7 高估 0.084 | 做删失感知拟合（P0-3，1 小时） |
| 早警口径 | 自参照泄漏 0.087 | 论文与产品口径统一改"纯净口径" |
| 冷启动 | 只依赖同伴数据（不需要学生历史） | **少样本方案可落地**（§3.2） |
| 输出形式 | 段级单点、无定位、无拒答 | 加**拒答带** + 段内定位（坐下级诊断通道已有 0.607） |
| 覆盖缺口 | 完课仍挂科 18.8% 判别弱（0.774） | 少样本在这块性价比最高（K=2 就 0.671） |
| 部署风险 | 跨段迁移口径混乱 | 统一到"阶段级 RF + 段锚定标准化"（跨段 0.9184，掉 0.010） |
| 证据强度 | 只在 CS1 一个数据集 | **外部数据集验证仍是投稿硬缺口** |

### 4.2 新模型 CS1-FSP 的落地规格

```
输入：段 p 的无标签学生群体（≥150 人）+ K 个已标注案例（K 个掉队 + K 个未掉队）
 ① 段锚定转导标准化：绝对量特征用该段自己的中位数/MAD（只用无标签行）
 ② 特征：同伴相对 10 维（K≤2 时只用 peer_z_submit 1 维）
 ③ 打分：K≤2 → 逻辑回归；K≥4 → RF（100–300 树）；不使用伪标签自训练
 ④ 校准：交叉拟合 Platt（ECE 0.068 → 0.013）
 ⑤ 拒答：K<4 或该段无标签样本 <100 → 输出"证据不足"，不给分数与阈值
输出：段级风险分 + 段内定位（第几次坐下/第几题）+ 拒答标记 + 标注成本提示
```

### 4.3 三条落地建议

1. **产品口径（写进销售与教师端）**："每校每学期人工确认 8–16 个案例（老师看一眼谁掉队），系统就能在新段/新学期第一天给出预警；不足 4 个案例我们不给结论，只给'证据不足'。"
   —— 这是把模型能力翻译成**可承诺的交付形态**，而不是承诺 0.93 的精度。
2. **工程优先级**：① 校准 + 拒答带（1 天，直接决定能不能上线）② 少样本冷启动通道（3 天）③ 终局画像专项（少样本在 K=2 就有 0.671）④ 外部数据集验证（投稿硬缺口，1 天人工探路）。
3. **停止投入**：深度少样本（FoMAML / 度量学习 / 原型网）—— 三种实现 + 本次对照（K 增大反而变差）已足够判负；不再投人。

## 5 · 风险与边界

1. **所有少样本结论目前只在 CS1 一个数据集上成立**；外部数据集验证（论文附录 B）仍是投稿硬缺口。
2. **段锚定转导标准化需要段内有足够多的无标签样本**（CS1 每段 215–471 行）。新学校/新班级若一段不足 ~150 人，转导部分的收益会衰减 → 需要退化策略（退回段锚定 + 全局先验 + 拒答）。
3. **K=1/2 的方差大**（本次重复间标准差 0.03–0.06，见 `cs1_fs.json` 的 `auc_std`），不能只报均值；产品口径必须配拒答带与置信区间。
4. **少样本不能替代全监督**：标签充足时仍以段级 RF（pooled 0.9289）为准；少样本的价值在"新段/新学期第一天就能出信号"。
5. **段级判别的本质是非线性交互**（"提交少于同伴 且 编辑远多于运行 且 焦点碎片化"），这解释了为什么线性原型在小 K 下落后 RF，也解释了为什么"换模型"这条路在本项目上已死。
6. **本提案的 0.896 / 0.875 等数字是"段内冷启动"口径**（support 与 query 同段）；**跨段迁移必须走"全标签训练 + 段锚定标准化"**（0.9184），两者不能混用。

### 7.1 方法谱系一览

| # | 方法 | 作用（解决什么） | 创新点 | 实例 / 数字 |
|---|---|---|---|---|
| 1 | **阶段级任务形式（CS1-SHR）** | 把"预测谁挂科"（不可标注）换成"**他在哪一段停止推进**"（可从日志自动推导） | ① 标签**从日志事实推导**（drop = 该生到达的最远段且从未到 part7）；② **同伴相对特征**（peer_z）为主表征；③ 显式处理右删失 | 段级 pooled **0.9258**；`peer_z_submit` 在 **7 个段全部是第 1 重要特征**（0.057–0.127，第 2 名 0.007–0.024，领先一个数量级） |

### 7.2 三条可写进投稿的创新主张

1. **任务形式的创新**：用日志事实**自动推导"停止推进"标签**，把不可标注的"预测谁挂科"变成可标注的段级 hazard 任务；并用实测证伪"更细粒度更好"（习题级 **0.4920**，低于随机）→ 提炼出**粒度—基准率—归纳偏置三律**。
2. **同伴相对表征 + 阶段条件化解释**：`peer_z_submit` 在 7 个段都是第 1 重要特征，跨阶段 HR 0.15–0.41 → 把"相对同伴少提交"从统计相关变成**可干预的具体动作**（counterfactual 给出改法与降幅）。
3. **诊断与判别的分工 + 早警时点定价**：深度模型判别线输给 GBDT（−0.03~−0.13）却在诊断线赢 1.8 倍 → **模型要按任务类型选**；并首次把"早"与"准"分开定价（整段 0.929 → 第 1 次坐 0.782 → 第 2 次坐 0.707）。
4. **（本次新增）少样本与冷启动的第四律**：小标签预算下**特征选择比模型选择更重要**（K=2：1 维 0.856 > 29 维 0.780），并给出可承诺的标注成本口径（**每段 8–16 个案例**）。

### 7.3 一个学生的完整链路（实例串讲）

以学生 **#311**（第 2 段）为例，看这套方法体系怎么串起来：

| 环节 | 方法 | 输出 |
|---|---|---|
| 段级判别 | CS1-SHR | 该段风险高分，判定"这一段之后他不再推进" |
| 早警定位 | IPSD 截断增广 | **第 3 题**时风险已到 0.993（整段共 30 题，他只做到第 8 题） |
| 卡点诊断 | 逐题同伴对照 | 卡点在**第 7 题**：1571 个事件、**编辑 776 次、只运行 47 次**；**第 8 题焦点 54 次/小时 vs 同伴 0.67** |
| 干预解释 | counterfactual | 若提交量回到同伴中位，风险 **0.99 → 0.44**；建议"先跑起来看报错再改" |
| 交付老师 | 周报 | 一句可照读的话 + 该题知识点 15 分钟 1:1 |

→ 这条链就是整个体系的价值：**从"这孩子有风险"到"他在第 7 题卡住、因为只改不跑、并且把提交量提到同伴水平能把风险砍一半"。**
