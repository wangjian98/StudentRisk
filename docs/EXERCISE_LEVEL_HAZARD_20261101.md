# 习题级 hazard 实验（2026-11-01）· 决策单元粒度的可学性边界

**问题**：把掉队判点从 part（题目分段）下沉到习题（exercise），能否得到更早、更可执行的预警？
**结论先行**：**不能——但不是因为特征不够好，而是因为粒度与事件基准率不匹配**。习题级 hazard 定位"停在哪一题"的 pooled AUC 只有 **0.492（低于随机）**，而 part 级同口径是 **0.9258**。同时习题级数据揭示了一个重要的行为学事实：**81.8% 的掉队是"段内中途停下"**。

---

## 1 · 数据结构勘查（`inspect_exercise_structure.py`）

| 项 | 结果 |
|---|---|
| 每个 part 的可用题量 | part1/2 各 30 题，part3 19，part4 16，part5/6 19，part7 11 |
| 触碰前缀一致性 | **97.1%** 的 (学生,part) 组触碰**连续前缀**，跳题仅 0.6% → "最后触碰的习题"可作停点 |
| (part,习题) 学生覆盖度 | 高：part1 第 1 题 475 人 → 第 30 题 407 人 |
| 习题级样本量 | **44,764** 行（每生 94.6 行），聚合耗时 40s（全量 2858 万事件） |

## 2 · 两个标签

| 标签 | 定义 | 用途 |
|---|---|---|
| `drop_final` | 该生**最终**会在某个 part 掉队 → 该生所有习题行都标 1 | **早期预警**（同标签下与 part 级公平对照） |
| `drop_at` | 该生掉队的**停点习题**（其最终 part 内最后触碰的习题）→ 258 个事件 | **经典 hazard**（与 part 级 drop 事件同构，可直接对照） |

## 3 · 结果

### 3.1 经典 hazard：定位"停在哪一题"

| 模型 | 判别单元 | 事件在比较单元内的占比 | overall AUC | **part 内 pooled** | (part,习题) 内 pooled |
|---|---|---|---:|---:|---:|
| **part 级 drop**（CS1-SHR 主干） | (学生, part) | **6.0%–17.6%**（part1 83/471 … part5 15/250） | 0.9353 | **0.9258** | — |
| **习题级 drop_at** | (学生, part, 习题) | **0.58%**（258 事件 / 44,764 行；每个 (part,习题) 细胞约 1 个正例 vs ~300 负例） | 0.4915 | **0.4920** | 0.4924 |

→ **习题级 hazard 低于随机**。这不是特征不足：任务本身在习题粒度上不可学（正例在每个比较单元内近乎唯一，模型无法从同层同伴中分离出"谁会停在这里"）。

### 3.2 同标签（drop_final）早期预警：习题级 vs part 级

按学生分组 5 折 × 3 seeds；行级 **part 内 pooled AUC**（个体判别力口径）：

| 习题级（截取前 k 题的前缀行为） | pooled | | part 级（截取前 K 段） | pooled |
|---|---:|---|---|---:|
| 前 1 题 | 0.5892 | | **前 1 段**（≈30 题行为量） | **0.7282** |
| 前 2 题 | 0.5926 | | 前 2 段 | 0.7615 |
| 前 3 题 | 0.6077 | | 前 3 段 | 0.7587 |
| 前 5 题 | 0.6186 | | | |
| 前 10 题 | 0.6306 | | | |
| 全部习题 | 0.6485 | | | |

→ **part 级在同标签下全面更优**；且"前 1 段"（≈30 题的行为量）的 0.7282 远高于习题级"前 10 题"的 0.6306 → **按行为量折算，part 级特征效率更高**。

### 3.3 预警点（drop_final 模型，阈值 0.5）

被标记的 (学生,part) 共 1163 个，其中真实最终掉队 561 → **精确率 0.48**；首次越阈在第 1 题的 758 个中精确率 0.54。远低于 part 级干预曲线（k=4 时全样本 0.7927）。

### 3.4 描述统计：**掉队是段内中途停下**（本次最重要的行为学发现）

| 指标 | 数值 |
|---|---|
| 掉队学生（258 人）停点=**段边界**（最终段全部题做完） | 47 人（**18.2%**） |
| 停点=**题内**（最终段中途停下） | **211 人（81.8%）** |
| 掉队生在最终段的完成比例 | 中位 **0.474**（p25 0.267，p10 0.067） |
| 对照：完课者在 part7 的完成比例 | 中位 **1.000** |
| 各 part 掉队率 | p1 17.6% / p2 17.3% / p3 9.7% / p4 13.8% / p5 6.0% / p6 9.3% / p7 0 |

→ 掉队的机制是**在一个段内逐步流失**（做着做着就停了），而不是"做完一段然后不开始下一段"。

## 4 · 三条结论

1. **决策单元的粒度必须与事件在比较单元内的基准率匹配**。part 级事件占比 6–18% → 可学（pooled 0.9258）；习题级事件占比 0.58%（每单元近乎唯一正例）→ 不可学（0.492，低于随机）。**把决策单元切得更细，并不会自动带来更好的模型，只会把可学问题变成不可学问题。**
2. **更细的粒度不换来更早的预警**。同标签对照下，习题级前缀特征在所有截止点上都低于 part 级聚合特征（0.589–0.649 vs 0.728–0.762）。CS1-SHR 以 part 为决策单元的选择得到实证支持。
3. **但习题级数据给出了一个产品级结论**：既然 81.8% 的掉队发生在段内中途，那么"等段结束才判"在产品上偏晚；**段内需要细粒度监控**，而"卡在哪一题"应当作为**诊断输出**（给老师的行动信息）而不是预测目标。

## 5 · 下一步（按价值排序）

| # | 事项 | 说明 | 成本 |
|---|---|---|---|
| 1 | **段内细粒度监控产品形态**：在段进行中持续输出"该生在本段的停滞风险"，不等段结束 | 由 3.4 的 81.8% 支撑；判别模型仍用 part 级，输出频率提到段内 | 1 天（工程） |
| 2 | **习题级诊断输出**：对被标记学生，回看其最后 3 道题 vs 同伴的耗时/编辑/运行差异 → 输出"疑似卡点题目" | 81.8% 段内停下 → 卡点可定位；这是**诊断**而非预测，不受 0.492 限制 | 1–2 天 |
| 3 | **把 3.4 的行为学结论写进论文** | "掉队=段内逐步流失"是一条新的、干净的行为学结论，且与"两类失效画像相反"互补 | 半天 |
| 4 | 若仍要在习题级做**预测**，必须换目标 | 例如"未来 3 道题内是否会停滞"（前瞻窗口而非事件定位）；基准率会从 0.58% 升到可用区间 | 2 天（可选） |
