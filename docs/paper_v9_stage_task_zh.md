## 1. 新摘要（替换 v8 §摘要）

> 面向编程学习者的学业风险预测研究长期面临一个结构性困难：学期末的"挂科/通过"标签与"学习者在课程中的真实卡点"之间存在长链条的语义鸿沟，导致模型要么被题目难度先验主导、要么因信息错配而无法早期预警。本文提出 **Stage-Risk：面向阶段性推进决策的两层学业风险评估框架**。第一层将学习者风险建模为**阶段级推进决策**——在每个题目分段（problem part）结束时预测"该学习者此后是否继续推进"，标签由 IDE 行为日志的推进轨迹直接推导，无需任何新增标注；第二层将各阶段告警聚合为学期级终局风险，以覆盖"全程推进但终局失败"的学习者。两层分别对应两种不同的失效模式：*推进停滞型*（低投入磨洋工）与*终局崩溃型*（高强度赶工、反复返工、注意力碎片化），二者在行为画像上相反、不可互相替代。
>
> 关键发现有三：其一，**阶段级任务不存在题目难度先验捷径**——仅用分段先验的基线 AUC 为 0.4164（低于随机），而学生级任务中同一基线高达 0.9135，说明任务形式的改变本身就消除了混淆；其二，**阶段级任务具备可用的早期预警能力**——仅用第一个分段的行为即可取得 part 内加权 AUC 0.9423，领先先验基线 0.31，而同一数据上学生级 lead-time 预测仅 0.65；其三，**两类风险需要两套信号**，仅用活跃度特征无法区分推进停滞与终局崩溃，需引入进度完成度、节奏比率与同伴相对位置等特征。
>
> 在架构层面，本文验证选择性状态空间 + 任务感知调制的组合在阶段级任务上与特征工程基线的相对关系：*（本节在 246 上完成阶段级 MetaMamba 实验后填入，模板见 §7.1）*。本文同时如实披露三项负面结果：任务对比辅助损失在监督任务中为负贡献、乘性调制相对加性拼接无必要性、跨分段泛化在当前数据规模下不可靠。

## 3. 新 §1.4 核心贡献（替换）

1. **提出阶段级推进决策任务形式（Stage-Risk）**：从 IDE 日志的推进轨迹直接构造阶段级标签，把风险评估从一次性终局判决改造为可定位时点的逐段决策；监督样本量从 473 提升到 2171（×4.6）。
2. **实证澄清了既有评估中的混淆来源**：证明学生级指标被题目难度先验主导（先验基线 AUC 0.9135），且该混淆会导致模型排名完全反转（组内/总体排名逆序 15/15）——这一发现本身对学习分析评测具有方法学意义。
3. **量化了"早期预警"的可实现边界**：学生级 lead-time 预测随前缀缩短而崩塌（0.65–0.83，低于先验），阶段级预测则稳定（0.93+），据此定位到"任务与预测时点错配"这一根因。
4. **提出并验证双层风险架构**：阶段级推进预警 + 学生级终局风险的组合，覆盖 81.2% 的挂科学习者（255/314），并识别出剩余 18.8% 的"全程推进仍失败"学习者的独立行为画像。
5. **如实披露三项负面结果**（TC 辅助损失为负贡献、乘性调制相对加性无必要性、跨分段泛化不可靠），并给出各自的适用边界。

## 4. 新 §3.1 问题形式化（替换）

### 4.1 符号

- 学习者集合 $\mathcal{S}$，$|\mathcal{S}| = 473$；分段集合 $\mathcal{P} = \{1,\dots,7\}$。
- 行为日志 $\mathcal{E} = \{(s, p, e, \tau, \tau_d)\}$，$|\mathcal{E}| = 28{,}588{,}309$，含 7 类事件。
- 阶段样本：$\mathcal{X} = \{(s,p) : s \in \mathcal{S},\ \exists e \in \mathcal{E}_s \text{ with part}(e)=p\}$，$|\mathcal{X}| = 2171$。
- 课程级标签 $y^{final}_s \in \{0,1\}$（挂科=1），来自课程官方结果。

### 4.2 第一层：阶段级推进决策

**推进轨迹**：对学习者 $s$，令 $p^{max}_s = \max\{p : (s,p) \in \mathcal{X}\}$。

**阶段标签**：
$$y^{stage}_{s,p} = \mathbb{1}\big[(s,p) \text{ 是其最远分段}\big] \wedge \mathbb{1}\big[p^{max}_s < 7\big]$$

语义：学习者在第 $p$ 段仍有活动，但此后**不再推进**。该标签完全由日志的客观事实推导，**无需任何人工标注**，且与课程级标签的信息重叠被显式度量（$\Pr(y^{final}=1 \mid y^{stage}=1) = 255/258 = 98.8\%$）。

**学习目标**：
$$\hat{p}^{stage}_{s,p} = f_\theta\big(\mathcal{E}_{s,p},\ p\big),\qquad
f_\theta:\ \mathcal{E}_{s,p} \mapsto (0,1)$$

**关键约束（防泄漏）**：$f_\theta$ 只能使用**截至第 $p$ 段结束**的信息。禁止使用 $p^{max}_s$、后续分段是否存在、时间上更晚的事件，以及任何课程级标签的派生量。

### 4.3 第二层：学期级终局风险

$$P^{final}_s = \sigma\big(\beta_0 + \beta_1 \cdot \max_p \hat{p}^{stage}_{s,p} + \beta_2 \cdot \overline{\hat{p}}^{stage}_s + \beta_3 \cdot \text{Progress}_s\big)$$

其中 $\text{Progress}_s = p^{max}_s / 7$ 仅在**学期结束后**可用于回顾性评估，不可在预警时点使用。

**两层为何缺一不可**：$y^{stage}$ 与 $y^{final}$ 并非等价——59 名学习者（占挂科者 18.8%）$p^{max}_s = 7$（全程推进）但最终挂科，其阶段级标签恒为 0；这些学习者在中段行为上呈现独立画像（见 §8 发现 4）。

## 5. 新增 §3.12 阶段级数据构造与防泄漏约束

### 5.1 构造流程

1. 分块扫描 IDE 日志（chunk = 1.5M 行），按 $(\text{student}, \text{part})$ 分组；
2. 每组按时间戳排序，仅保留**最晚的 $L=128$ 条事件**（与学生级口径一致；阶段内平均事件数 13,168，说明截断充分）；
3. 逐事件编码为 11 维：7 类事件 one-hot + $\log(1+\Delta t)$ 时间间隔 + 截止距离归一化 + part 归一化 + exercise 归一化；
4. 为消融准备 9 维（去掉 part/exercise 通道，任务身份只经 FiLM 注入）与 7 维（纯事件类型）。

### 5.2 三个必须写进论文的说明

1. **分段语义前提**：CS1 的 7 个分段存在顺序依赖（抽样 16 名学习者，时间上回退 0 例），"未到达分段 $p+1$"等价于"在此停滞"。**该前提在分段可并行选择的课程中不成立**，方法迁移需重新验证。
2. **同伴参照系的小样本退化**：各分段同伴数为 131/78/24/55/14/9/162，$n<20$ 的分段（5、6）上同伴归一化统计量不稳定，需经验贝叶斯收缩或回退。
3. **完成度指标的可污染性**：完成度（触及题目数 ÷ 分段题量）可能被"乱点题号刷提交"污染，需配合提交质量校验（如代码行数、run/submit 比、提交间隔）使用。

### 5.3 阶段级基线的特殊性质

阶段级 part-prior 基线（按分段先验、无泄漏）**AUC = 0.4164（低于随机）**。各分段的掉队率相近，故"分段难度"在阶段级任务中不构成混淆——这与学生级（0.9135）形成鲜明对比，也是阶段级任务作为主任务的核心理由。

## 6. 新 §4.3 评估协议（替换）

### 6.1 交叉验证

**按学习者分组 + 按课程级标签分层**的 5 折交叉验证：同一学习者的全部阶段样本必须落在同一折内。理由：阶段级样本是"行"，若按行分层，同一学习者的多个阶段行会同时进入训练折与验证折，模型可能借助学习者身份获得乐观偏差。实测该偏差在阶段级任务上不显著（按行 0.9294 → 按学习者分组 0.9322），但在**学生级**任务上会高估约 0.027（0.7955 → 0.7690）。**所有主结果以按学习者分组口径报告。**

### 6.2 指标体系

| 层级 | 指标 | 含义 |
|---|---|---|
| 总体 | ROC-AUC、Macro-F1、F1(pos) | 与既有工作可比 |
| **个体（主指标）** | **part 内加权 AUC**（pooled within-part AUC） | 排除分段难度差异后的个体判别力 |
| 个体 | judgeable AUC（正负例各 ≥10 的分段平均） | 抗小样本退化分段 |
| 增益 | **ΔAUC vs 对应层级的 part-prior** | 剥离先验后的净贡献 |
| 稳健性 | 配对 bootstrap（3000–4000 次）95% CI | 差异显著性 |

### 6.3 必报的基线

1. **part-prior baseline**：仅用分段先验（学生级 0.9135 / 阶段级 0.4164）——**必须进主表**；
2. **去 part 混淆的 RF 基线**：同伴归一化 + 完成度 + 节奏比率 + 自参照偏离；
3. **活跃度-only / 完成度-only / peer-only 消融**：证明判别力不是"数次数"。

## 8. 新 §5 分析与发现（替换）

**发现 1（方法学）**：学习分析中的"主任务"选择会决定结论是否成立。同一份数据、同一批模型，学生级指标被题目难度先验主导（先验 AUC 0.9135），导致模型排名在"个体判别力"口径下完全反转（逆序对 15/15）；改为阶段级推进决策后，先验基线降至 0.4164，模型排序与个体判别力重新对齐。

**发现 2**：阶段级判别力并非"数活跃度"——剔除全部活跃度维度后 part 内 pooled AUC 仅下降 0.0034（P=17.8%，不显著），而非活跃度特征（完成度、节奏比率、同伴相对位置、自参照偏离）单独贡献 Δ +0.0456（P=0.00%）。

**发现 3**：早期预警失效的根因是"任务与预测时点错配"，而非模型能力。学生级任务问"学期末是否挂科"，前缀行为对终局无因果路径；阶段级任务问"下一段是否推进"，刚结束的一段行为对下一步有直接因果路径。

**发现 4**：两类失效模式的行为画像相反 —— 推进停滞型表现为低投入磨洋工（强度中位 log 3.88，焦点切换 2.6/h），终局崩溃型表现为高强度赶工 + 注意力碎片化（强度 4.39，焦点切换 3.9/h，比通过者高 34%，删除率 27.8% vs 23.5%）。单一挂科概率无法同时刻画两者。

**发现 5（负面）**：任务对比辅助损失在学生级为负贡献（去除后 Macro-F1 +0.56pp，p≈0.45），阶段级结论待回填。

**发现 6（负面）**：跨分段泛化不可靠。留一分段交叉验证下，去混淆 RF 的加权 AUC 为 0.5000（等于随机），MetaMamba-7d 为 0.6134（part7 ROC 0.221，低于随机）。当前模型学到的是分段专属模式，尚不能迁移到新题目单元。

**发现 6'（负面 · 判决性）**：**在阶段级任务上，MetaMamba 显著劣于去 part 混淆的随机森林**（pooled 0.8841 vs 0.9262，Δ = −0.0421，P(≤0) = 99.85%）。该结论在"去活跃度"与"全特征"两种 RF 口径下均成立。同时，MetaMamba 的维度规律为 11d > 9d > 7d，与 v8 "架构 >> 特征维度"的结论方向相反。**因此，若以"是否优于同口径特征工程基线"作为架构价值的验收标准，则选择性状态空间 + 任务感知调制在本任务上不成立**；论文的贡献应重新定位到任务形式与评估口径，架构部分作为对照与工程实现呈现。

**发现 6''（负面 · 四项全开后仍判负）**：把验收条件推到最严——"去 part 混淆 + 残差化 + 阶段级 + 跨 part 泛化"四项全开，且两 arm 完全对称，MetaMamba 的**每一个**变体仍全部输给同口径 RF：主判定 Δpooled = **−0.1302** [−0.1649, −0.0975]，P(≤0) = **100.00%**；即便给 MM 最宽松的"上下文不残差化 + 喂 RF 同款特征"加强版，Δ = −0.0794，仍 100% 显著为负。LOPO（跨 part 泛化）同样判负：MM 加权 0.8681 vs RF 0.9128，Δ = −0.0447，P(≤0) = 100.00%。**且 RF 训练仅 15 秒、MetaMamba 需 38–76 分钟。** → **架构贡献判定为不成立，论文主模型换 RF，MetaMamba 降为对照/负结果。**

**发现 7（负面）**：乘性调制相对加性拼接无必要性（喂对任务 id 时两者混淆矩阵完全一致，概率相关 r=0.9986）；FiLM 的真实作用是补充分段先验信息，而非建模分段内判别差异。

## 9. 新 §6.2 局限性（替换）

1. **单一数据集**：全部结论基于 CS1（473 学习者 / 7 分段 / 2,858 万事件），未做外部数据集迁移验证。
2. **分段语义依赖**：推进决策的前提是分段有序依赖且不可并行跳过；对分段可自选的学习者需重新定义标签。
3. **小样本分段退化**：分段 5、6 的同伴数仅 14、9，其个体判别力估计不可靠；主指标只报 part4/part7。
4. **标签与结局高度耦合**：阶段级标签与课程级标签信息重叠 98.8%，阶段级的高判别力部分来自"更贴近结局定义"而非更强的泛化；应理解为"更可用的任务定义"，而非"更强的模型"。
5. **完成度可污染**：触及题目数指标可能被无效提交刷高。
6. **早停使用验证折**：与既有工作一致，但在严格嵌套交叉验证下数值可能下降。
7. **跨分段泛化未解决**（见发现 6、6''），跨课程/新题型的部署仍不可用：LOPO 加权 AUC RF 0.9128 / MetaMamba 0.8681，两者均远低于同 part 内 AUC → 换课程仍显著掉点。
8. **阶段级残差化为负结果**：打分层残差（MM 0.8465 → 0.7643）与特征层剔除活跃度（RF 0.9258 → 0.8988）在阶段级均为负；残差化只在学生级有效，本文不应在阶段级声称残差化收益。

## 10. 新 §7 结论（替换）

本文的主要贡献不是把某个指标从 0.92 推到 0.95，而是**把学业风险评估的任务形式重新对准干预决策**：从"学期末他挂不挂科"改为"每做完一段他还走不走"。这一改动带来三项可验证的收益——消除了题目难度先验对指标的支配（先验基线 0.9135 → 0.4164）、恢复了可用的早期预警能力（lead-time 0.65 → 0.94）、把监督样本从 473 扩到 2171。同时本文也给出了三项诚实的负面结论：辅助对比损失无益、乘性调制非必要、跨分段泛化不可靠。在阶段级任务上，选择性状态空间 + 任务感知调制**未通过**与同口径特征工程基线的对照（0.8841 vs 0.9262，P(≤0)=99.85%）；在把验收条件推到"去 part 混淆 + 残差化 + 阶段级 + 跨 part 泛化"四项全开、两 arm 完全对称的最严口径下，该结论进一步加剧（主判定 Δpooled = −0.1302，P(≤0)=100.00%；跨 part 泛化 LOPO 加权 0.8681 vs 0.9128，Δ = −0.0447，P(≤0)=100.00%），且随机森林训练仅需 15 秒而 MetaMamba 需 38–76 分钟：在该口径下，**决定性能的是任务形式与特征设计，而不是架构**。这一负面结论与本文另外两项负面结果（TC 无益、乘性调制非必要）方向一致，共同提示：在学习分析的中小规模行为数据上，**"更复杂的时间序列架构"并非性能的必要条件**——把建模目标对准可干预的决策时点、剥离先验混淆、并配合去混淆的相对化特征，其收益（学生级 0.7690 → 阶段级 0.9262）远超任何架构改动。
