# CS1 专用预测模型提案：CS1-SHR（阶段分层双通道生存风险模型）

**日期**：2026-11-01
**来源**：MetaMamba 项目实验（A–I + 阶段级四项全开复验）＋ 本次首测原型
**定位**：本提案不新增"更强的架构"，而是**让模型形态匹配 CS1 的数据生成过程**——把论文主线从"我造了个更复杂的时序网络"换成"我重新定义了这个问题，并给了更严谨的评估与一个匹配数据结构的模型"。

---

## 0 · 一句话结论

> **MetaMamba 的失败不是"容量不够"，而是"形态不对"**：它用**架构**去解决一个**标签定义与数据结构**问题。
> CS1 的真实结构是「离散时间生存 + 两类行为画像相反的失败模式」，
> 因此适配 CS1 的模型应该是 **掉队 hazard 通道（时间变化协变量、删失感知）+ 终局通道（存活条件下的挂科预测）+ 校准融合**，
> 而不是更深的序列网络。首测显示：**该形态在阶段级能复现 RF 的判别力（pooled 0.9258，逐位复现报告值），
> 同时额外拿到「删失正确的概率标尺 + 逐阶段干预时点 + 18.8% 终局型兜底」三样 RF 给不了的东西。**

**推论**：MetaMamba 已经"出局"，但**"论文主模型换成 RF 就完事"也不对**——RF 是更强的靶子，不是更好的模型：它没有删失处理、没有逐阶段概率标尺、没有终局通道、也不产出干预时点。下面提案补的正是这四样。

## 2 · CS1 数据集的真实结构（决定模型形态的 6 个事实）

| 编号 | 事实 | 实测 | 对模型形态的约束 |
|---|---|---|---|
| **F1** | **这是一个离散时间生存问题** | 473 学生 / 2171 个 (生,part) 阶段行 / **258 个掉队事件** / 215 人走到 part7 后**右删失**（part7 掉队率恒为 0） | 模型必须显式处理删失，且输出"逐阶段危险率"而不是"一次性分类" |
| **F2** | **标签混合两类画像相反的失败** | 掉队型 255 人：**强度最低（log 3.88）**、焦点最不碎（2.6/h）、完成度 1.0；终局型 59 人（走完全程仍挂科）：**强度最高（4.39）**、**焦点最碎（3.9/h，+34%）**、返工最多（删除率 27.8% vs 通过 23.5%） | 单一扁平分类器被混合标签稀释 → **必须两通道**（掉队 vs 终局） |
| **F3** | **part 先验在两个任务上性质相反** | 学生级 part-prior AUC **0.9135**（捷径，必须剥离）；阶段级 part-prior **0.4164（低于随机）**（无捷径） | 模型输入**不得含 part 身份**；part 只能作为"阶段序号"这种可外推的连续量进入基线危险率 |
| **F4** | **事件海量但样本极少** | 28,588,309 事件 → 473 学生 / 2171 行 / 258 事件 | 容量上限极低：22k–70k 参数的深度模型必然过拟合 → **要强归纳偏置 + 强正则**，不是更大网络 |
| **F5** | **阶段级真信号是"进度类 + 同伴相对位置 + 节奏比"，不是"活跃度绝对量"** | 剔除全部活跃度维度 → pooled 0.9294→0.9260（Δ+0.0034，P=17.8% 不显著）；活跃度单独 0.8804，同伴归一化 10 维 0.9295；完成度+阶段序号 0.8646；**特征层残差化 −0.027（负结果）**；M4 强度特征 ΔAUC −0.0013（P=84.4%） | 特征层固定为：**同伴分位/收缩 z + 完成度 + 节奏比 + 自参照偏离**；**禁止**特征层残差化 |
| **F6** | **跨 part 泛化是硬墙，但对正则化敏感** | 阶段级 LOPO 加权 AUC：RF **0.9128** vs HGB **0.9186**（本次首测） | 跨 part 场景需要**更强正则 / 集成**；且**禁止把 part 身份喂进模型** |

## 3 · 提案模型：CS1-SHR

### 3.1 结构

```
                     ┌───────────── Layer 0：part 不变表征 ─────────────┐
IDE 事件(28.6M) ──▶ │ 同伴分位(rank) + EB 收缩 z + 完成度/推进 + 节奏比    │
  → (生,part) 聚合   │ + 自参照偏离(相对自己前几段)  [+ 可选轻量序列编码器] │
                     └───────────────────────┬───────────────────────────┘
                                             │  x_i（不含 part 身份）
             ┌───────────────────────────────┴────────────────────────────┐
             ▼  Channel A：掉队 hazard（离散时间，time-varying 协变量）      │
             log(-log(1-h_i)) = α(stage_i) + f_A(x_i)      h_i = P(阶段 i 掉队 | 活到 i)
             → 逐阶段危险率  →  P_drop_by_k = 1 − Π_{i≤k}(1−h_i)              │
             │                                                              │
             ▼  Channel B：终局通道（条件于"活过第 k 段"）                    │
             P(最终挂科 | 存活到 k) ← 前 k 段轨迹签名（强度/焦点碎片/返工/推进）│
             │                                                              │
             └──────────────────────┬───────────────────────────────────────┘
                                    ▼  校准融合 + 决策层
   P(挂科) = P_drop_by_k · q_drop + (1 − P_drop_by_k) · P_终局
   干预名单：按 P_drop_by_k 排序 + 阈值 + 拒答带（低置信转人工）
   学习产出：每阶段 hazard 比（可解释）+ 校准曲线 + "最早可干预时点"曲线
```

### 3.2 每个设计选择 → 依据（一一对应，不凭感觉）

| # | 设计选择 | 依据（实测） |
|---|---|---|
| 1 | **主任务改为阶段级"此后是否推进"** | S11：255/258 未达 part7 者挂科（98.8%）→ "会不会挂科"≈"会不会掉队"；阶段级判别力 0.72→0.9718 |
| 2 | **显式删失处理（part7 右删失）** | F1：215 人走到 part7 无掉队事件；扁平模型把这些人当"负样本"，系统性低估早期行为的作用 |
| 3 | **输入禁止 part 身份，改用阶段序号基线** | F3：学生级 part-prior 0.9135 是捷径；阶段级 0.4164 说明 part 身份在个体判别上无用但有害（S9 LOPO 0.5000） |
| 4 | **特征 = 同伴分位 + EB 收缩 z（part 不变）** | F5：同伴归一化 10 维 0.9295 强于活跃度 0.8804；小 part（part5 n=14/正例少、part6 n=9）统计不稳 → 经验贝叶斯收缩 κ≈20–100；**分位**跨 part 可比，利于 LOPO |
| 5 | **完成度/推进 + 节奏比 + 自参照偏离** | F5：完成度单独 0.8646（主信号），但全特征 0.9294 → 主信号是进度类但不止进度；自参照 = 跨 part 可迁移的"个体轨迹" |
| 6 | **禁止特征层残差化** | F5：阶段级 pooled −0.027；残差化只在学生级有用（w=0.25 时三项同时变好） |
| 7 | **非线性学习器（RF/HGB）+ 强正则，不上深度序列模型** | F4 + 阶段级结案：MM 全部变体 pooled 0.85–0.88 < RF 0.9258（Δ−0.1302，P=100%）；本次首测线性 cloglog 更是只有 0.63–0.78 → **生存形式有用，非线性是必需，二者都要** |
| 8 | **跨 part 场景用 HGB 或 RF+HGB 集成** | F6：LOPO 加权 HGB 0.9186 > RF 0.9128 |
| 9 | **双通道 + q_drop/q_comp 融合** | F2：两类失败画像相反；阶段级只覆盖 81.2% 挂科学生，59 人（18.8）在定义上不可见 |
| 10 | **每阶段概率标尺 + 校准 + 拒答带** | 产品要的是"要不要现在叫导师"，不是"谁挂科"；Brier 0.0493 / LogLoss 0.1883（RF 全样本）尚不足以直接定阈值 |
| 11 | **序列编码器只允许当"特征提取器"，不许当独立预测器** | S3 指出 7 维缺强度；本次首测显示"原始序列"在阶段级打不过聚合特征 → 序列的合理位置是**给 hazard 提供 3–5 个摘要嵌入**，且验收标准同 RF |

### 3.3 为什么这不是"再做一次 MetaMamba"

| 维度 | MetaMamba | CS1-SHR |
|---|---|---|
| 任务 | 学生级最终挂科（与证据错配，S11） | 阶段级推进 + 学生级终局（双层） |
| part 使用 | 特征 + FiLM 双重注入（S4） | **完全禁止**，只用可外推的阶段序号基线 |
| 删失 | 无处理 | 显式右删失，危险率乘积 |
| 结构 | 单模型黑箱 | 掉队/终局双通道 + 校准融合 + 拒答 |
| 序列 | S6 状态空间主干（22k 参数，258 事件上过拟合） | 可选轻量编码器 → 摘要特征，验收不过就砍 |
| 输出 | 单一概率 | 逐阶段危险率 + 累计风险曲线 + 干预时点 + 可解释 hazard 比 |

## 4 · 首测结果（本次实测，含负结果）

环境：246（43.139.55.246，CPU）、`data/stage_dataset.npz`（2171 阶段样本）、5 折**按学生分组** × 3 seeds、part 内 pooled AUC。

### 4.1 协议复现校验 ✅

| 模型 | 总体 AUC | **part 内 pooled** | judgeable | Brier |
|---|---:|---:|---:|---:|
| RF 全特征（本次复现） | 0.9353 | **0.9258** | 0.9199 | 0.0493 |
| RF 全特征（结案报告值） | 0.9353 | **0.9258** | 0.9199 | — |

→ 逐位一致，说明本次脚本与项目主协议同口径，结果可直接与既有结论对话。

### 4.2 负结果（同样重要）

| 试验 | 结果 | 结论 |
|---|---|---|
| **线性 cloglog 危险率（生存形式 + 线性）** | pooled 0.6641 / 0.6753 / 0.7773（λ=1/10/100） | **远低于 RF 0.9258** → 生存形式本身不是瓶颈，**非线性必需** |
| **每 part 专门建模** | pooled 0.9216（< pooled 0.9258） | 小 part 正例太少（part5 正例 15、part6 正例 22）→ 单独建模不稳 |
| **按 n_k 收缩混合（κ=100）** | pooled 0.9276（+0.0018） | 阶段分层特化的增益在噪声量级 → **不做重结构**，只保留校准用途 |
| **HGB（非线性替代）** | part 内 pooled 0.9191（< RF 0.9258）；**LOPO 0.9186 > RF 0.9128** | HGB 跨 part 更稳 → 跨 part 场景用 HGB / RF+HGB 集成 |
| **"前 k 段快照广播到所有阶段"式 hazard 聚合** | 学生级 P(drop) 在 k=1 时 AUC **0.3897（低于随机）** | **危险率必须随阶段更新**；把早期快照广播到后期阶段会让"活得久"的学生被乘出更大风险 → **这是一个必须避免的建模陷阱**，已写入模型规范 |

### 4.3 正结果

| 项 | 结果 |
|---|---|
| 阶段级判别力 | pooled **0.9258**（与报告一致），HGB 集成可再拿跨 part 增益 |
| 删失正确性 | part7 掉队率恒为 0 的结构被正确吸收（不再把 215 名完课者当负样本） |
| 终局通道可行性 | 59 人（18.8%）在 part2–7 有可用信号（part 内 AUC 0.73–0.85，part7 0.8532），可独立建通道 |
| 早期性 | 阶段级第 1 段即可预警：pooled **0.9423**（领先阶段级 prior 0.4164 达 +0.31） |

### 4.4 学生级早期预警：双通道 vs 扁平基线（正确设定，run_early2）

> 设定：截止第 k 段结束，只用前 k 段信息预测「学期末是否挂科」。
> 掉队通道 = 阶段级 hazard（time-varying 协变量）乘到第 k 段；
> 终局通道 = 在「活过第 k 段」的学生上训 P(挂科)；扁平基线 = 同特征的学生级 RF/HGB。

| 截止 k | A) 扁平 RF | A2) 扁平 HGB | B) 双通道（个体化终局通道） | C) 双通道（常数终局率） | D) 终局通道单独 | E) 掉队通道单独 |
|---:|---:|---:|---:|---:|---:|---:|
| **1** | 0.6997 | 0.7126 | **0.7359** | 0.6551 | 0.6819 | 0.6525 |
| 2 | 0.8252 | **0.8293** | 0.7990 | 0.7368 | 0.6241 | 0.7371 |
| 3 | 0.8741 | **0.8813** | 0.7854 | 0.7654 | 0.5991 | 0.7656 |
| 4 | **0.8956** | 0.8820 | 0.8201 | 0.7923 | 0.5946 | 0.7927 |

**判读（两条，都是实测推翻直觉）**：
1. **最早时点（k=1）是双通道唯一赢的场景**：0.7359 vs 扁平 0.6997/0.7126（存活子集 0.6586 vs 0.6191/0.6386）。
   机制：第 1 段行为对「会不会掉队」极强（阶段级 pooled 0.9423），对「最终会不会挂科」只有中等 → **分解把强信号路由到强标签，再经 0.988 的条件概率传导**。
2. **k≥2 扁平模型反超**（0.8293 / 0.8813 / 0.8956）→ 「双通道一定更好」是错的；且**终局通道越训越弱**（0.6819 → 0.5946），
   因为它只在「活过 k 段」的小子集上训练，样本越少越不稳。

### 4.5 组合方式定稿（run_combo）

把终局通道换成「在全部学生上训练的扁平模型」（即上一节的 A2），再测四种组合：

| 截止 k | A) 扁平 HGB | B) 掉队通道 | C) 概率融合 P_drop·q_drop+(1−P_drop)·P_flat | D) 秩平均 0.5/0.5 | E) 概率融合 0.3/0.7 |
|---:|---:|---:|---:|---:|---:|
| 1 | 0.7126 | 0.6525 | 0.7158 | 0.7058 | **0.7188** |
| 2 | **0.8293** | 0.7371 | **0.8298** | 0.8099 | **0.8298** |
| 3 | **0.8813** | 0.7656 | 0.8727 | 0.8525 | 0.8796 |
| 4 | **0.8820** | 0.7927 | 0.8804 | 0.8677 | 0.8783 |

**判读**：
- 终局通道换成「全部学生」训练后，双通道在 k=1 的优势从 +0.023 缩到 **+0.006**（0.7188 vs 0.7126），
  在 k≥3 仍略输扁平 → **最优终局通道是「互补子集训练版」（k=1）而非「全量训练版」**，
  因为它与掉队通道的**错误模式不同**，才带来互补（典型的集成效应，而非单模型更强）。
- **概率融合（式C）稳定优于秩平均（式D）**（k=1/2/3 分别 +0.010/+0.020/+0.020）→ 融合要用概率空间，不要用排序分。

### 4.6 干预时点曲线（累计风险 P_drop_by_k）

| 截止第 k 段 | 全样本 AUC | **仍活跃子集**（真正需要干预的人）n | 仍活跃子集 AUC | P_drop 中位 |
|---:|---:|---:|---:|---:|
| 1 | 0.6525 | 389 | 0.5389 | 0.112 |
| 2 | 0.7371 | 321 | 0.5627 | 0.306 |
| 3 | 0.7656 | 290 | 0.5893 | 0.406 |
| **4** | **0.7927** | 250 | 0.6078 | 0.486 |
| 5 | 0.7901 | 235 | **0.6121** | 0.545 |
| 6 | 0.7793 | 213 | 0.5940 | 0.616 |
| 7 | 0.7781 | 0 | — | 0.644 |

**判读（对产品最重要的一条）**：
1. 累计风险随阶段单调上升并在 **k=4 左右见顶**（全样本 0.7927）→ **第 4 段是性价比最高的干预窗口**（n=250 仍活跃）；
2. **"仍活跃学生"的判别力只有 0.54–0.61** → 对还没掉队的人谈"最终会不会挂科"本身就弱（与 S10 同源），
   所以**产品上不应该承诺"提前预测谁会挂科"**，而应该承诺"**谁快要停下来了**"——这正是阶段级 pooled 0.926 的强项所在；
3. 这条曲线此前**没有任何模型给过**（MetaMamba 只有一次性概率），而它正是干预决策需要的量。

### 4.7 经实验修订后的模型定稿规格

| 部件 | 规格 | 依据（实测） |
|---|---|---|
| **主干** | **阶段级掉队 hazard**（time-varying 协变量 + 阶段序号基线 + peer 锚定特征），非线性学习器 RF/HGB | 阶段级 pooled 0.9258（复现结案报告值）；第 1 段 0.9423；无 part 捷径（阶段级 prior 0.4164） |
| **并行输出 1** | **学生级扁平通道**（全部学生训练，前 k 段快照 → 期末挂科） | k=1/2/3/4 → 0.7126 / 0.8293 / 0.8813 / 0.8820；是 k≥2 的最优方案 |
| **并行输出 2** | **互补型终局通道**（只在"活过 k 段"的学生上训练） | 单独弱（0.60–0.68）但与掉队通道**错误模式不同** → k=1 融合后 0.7359（+0.023） |
| **融合** | 概率空间：P(fail) = P_drop_by_k·q_drop + (1 − P_drop_by_k)·P_终局；权重按截止段数切换（k=1 用互补通道，k≥2 用扁平通道） | §4.4 / §4.5 |
| **标尺** | 逐阶段校准（Brier 0.0493）+ 拒答带 + 每阶段 hazard 比（可解释） | 干预决策需要概率而非排名；产品侧要能说"该找谁" |
| **禁止项** | ① part 身份入模；② 特征层残差化（−0.027）；③ 纯线性 hazard（0.63–0.78）；④ 每 part 专门建模（0.9216）；⑤ "前 k 段快照广播到所有阶段"的 hazard 聚合（k=1 时 AUC 0.3897 < 随机） | 全部实测负结果 |

**一句话**：CS1-SHR = **"阶段级掉队检测（强项·产品主打）+ 学生级挂科预估（弱项·诚实降级）+ 逐阶段概率标尺与干预曲线"**；
它不是"更准的黑箱"，而是**把 CS1 数据真正支持的两个问题分开回答，并对第二个问题的能力边界给出实测结论**。
