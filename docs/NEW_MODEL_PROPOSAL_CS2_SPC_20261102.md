# StudentRisk 现有模型不足分析 + 新深度学习模型提案：CS2-SPC

> 2026-11-02 ｜ 王建命题：「分析 studentrisk 现有模型的不足，并根据实验结果提出新的深度学习模型，给出依据」
> 立场：**基于本项目已完成的实测**，不是新设想。每一个设计选择都挂一条已跑出来的数字。
> 协议：按学生分组 5 折 × 3 seeds，peer 统计量只用训练折，主指标 = part 内 pooled AUC。

---

## 0 · 结论先行

**现有模型的主要问题不是"学习器不够强"，而是三处错配：决策单元错、归纳偏置错、输出形式错。**

- **决策单元错**：阶段级整段聚合把"卡在哪"的信息抹平（段内判别天花板 0.9258）；换到习题级又太细，事件基准率不匹配 → pooled 0.4920，**低于随机**。
- **归纳偏置错**：主导信号是"相对同伴的提交量"（`peer_z_submit` 在 6/6 有掉队正例的分段都是第 1 重要特征，领先第 2 名一个数量级），但现有实现只把它当作 31 维里的**一个标量**交给树去切分，模型没有任何"我相对于同伴"的先验。
- **输出形式错**：输出是段级**单点**风险，既不能回答"卡在第几题/第几次坐下"，也不能在早警口径下自洽（整段聚合含未来证据）。

**新模型 CS2-SPC**（Sitting-anchored Peer-contrastive Hazard Transformer）：以**习题为 token、坐下为观测锚点**的因果 Transformer + **连续进度条件化 FiLM** + **离散时间 hazard 头** + **同伴成对对比损失**，并保留阶段级通道做概率空间融合。

**已实测的三条边界（不要再踩）**：换学习器无效、加特征无效、直接优化主指标无效。见 §2。

## 2 · 六条负结果统一成一个命题

> **命题（粒度—基准率—归纳偏置三律）**
> ① 决策单元的粒度必须与事件基准率匹配：太粗 → 信息被聚合抹平；太细 → 基准率塌陷、信号被噪声淹没；
> ② **"结构"的价值在于定义观测单位，不在于提供特征**（会话结构 14 维单独 0.8215、加进特征集变差 −0.0058、放进坐下级截断也毫无增量 0.8644 vs 0.8665）；
> ③ 主指标是评估口径，不能当训练目标硬套。

**六组负结果的归位**：

| 负结果 | 数字 | 被哪条律解释 |
|---|---|---|
| 习题级 hazard 失败 | 0.4920（低于随机） | ① 粒度太细，基准率塌陷 |
| 段内截断只到 0.7915 | 前1题 0.7915 / 前3 0.7935 / 前8 0.7979 | ① 仍偏细 |
| 坐下级截断 0.8665 | 第1次坐下 **+0.075** over 习题级 | ① 找到匹配粒度 |
| 多尺度/会话结构加进去变差 | −0.0058；坐下级内 0.8644 vs 0.8665 | ② 结构≠特征 |
| LambdaRank −0.0229 | P=99.05% | ③ 口径≠目标 |
| 序数回归 −0.0169 | P=97.1% | ③ 换标签形式无效 |

**这三条律直接决定了新模型该长什么样**：不换学习器、不加特征、不换标签，而是**换决策单元（坐次）+ 换归纳偏置（同伴对比 + 进度调制）+ 换输出形式（hazard 曲线 + 定位 + 拒答）**。

## 3 · 新模型：CS2-SPC

### 3.1 一句话

**Sitting-anchored Peer-contrastive Hazard Transformer**：以习题为 token、坐下为观测锚点的因果 Transformer，把"段内时序细节"与"同伴相对位置"两路证据在**坐次**这个正确的决策单元上对齐，输出离散时间 hazard 曲线（段内早警 + 卡点定位）。

### 3.2 结构

```
每 (学生, 分段) 的习题序列（按题序）          ← token = 习题
  │
  ├─ token 特征 22 维：8 事件计数(log1p) + 5 率 + 3 时间 + 4 位置 + 2 截止期
  ├─ 阶段级上下文 31 维（A4+B3+C2+peer-z12+SELF10）逐 token 广播
  │      ↑ 与 RF 基线**完全同源**（同折 peer 统计量，截断口径一致，早警不泄漏）
  │
  ▼
Linear(53→64)+LN  +  位置嵌入
  ▼
连续进度条件化 FiLM：u = 题序/基准题量  →  γ,β   （★ 不用 part 身份，见 §3.3③）
  ▼
2 × 因果 Transformer Encoder（d=64, 4 heads, ff=128, dropout 0.1, norm_first）
  ▼                                   ↓
坐次末 token → 离散时间 hazard 头 h_k   注意力池化 → 段级 risk logit
  │
  ▼
L = L_surv(离散时间生存) + L_part(段级 BCE, pos_weight=7.41) + λ·L_peer(同伴成对对比)
```

### 3.3 五个组件，每个都挂一条实测依据

**① 决策单元 = 坐下（不是习题，不是整段）**
- 依据：习题级 pooled 0.4920 低于随机；坐下截断第 1 次 **0.8665（+0.075 over 习题级前1题 0.7915）**，且按行为量对齐后仍领先（一次坐下中位含 11 题 vs 前 8 题 0.7979）。
- 落地：token 粒度取习题（数据量足够：44,764 行），但**观测锚点与输出时点取坐次**——每次坐下结束输出一次 hazard。

**② 同伴成对对比损失（`L_peer`）**
- 依据：`peer_z_submit` 在 6/6 有掉队正例的分段都是第 1 重要特征（领先一个数量级）；counterfactual 5 例唯一可干预特征全是它。
- 做法：同段内成对比较，peer_z 提交量更低者风险应更高 → 成对 logistic；**组 = part**（不是 part 排序任务，这正是 LambdaRank 失败的地方）。
- 与 LambdaRank 的区别（必须写进论文，避免被误读为重复已被证伪的方向）：
  - LambdaRank 把**主指标**当训练目标（组=part，损失=排序）；
  - `L_peer` 只优化**一个可解释的中间目标**（同伴序），且是**辅助项**（λ=0.3），主损失仍是生存 + 段级 BCE；
  - 因此它是"**换任务形式**"，不是"直接优化主指标"。

**③ 连续进度条件化 FiLM（而不是 part 身份）**
- 依据：`rem_over_ins` p2–3 HR 2.5–2.7、`peer_z_paste` p4–5 HR 2.2–5.2、`peer_z_focus_lost` p1–2 HR 1.9–2.2 → **卡住表征随进度变化**，需要"条件化"的读特征方式。
- 但 "part 身份入模" 历史上 LOPO = **0.5000（随机）** → 绝不能用 part embedding。
- 解法：FiLM 的条件量取**连续进度 u = 题序/基准题量**（可跨 part 泛化），而不是 part 身份。

**④ 因果注意力 = 早警口径自洽**
- 依据：阶段级整段聚合用于早警时含未来证据，必须靠截断增广才能对齐（IPSD 前 1 题只有 0.7915）。
- 做法：Transformer 用 causal mask + padding mask，模型**结构上**无法看到未来；早警 = 只喂前 K 次坐下的 token。

**⑤ 双头输出（hazard 曲线 + 段级风险）**
- 依据：81.8% 掉队者最终段中途停下；周报原型已能给出"停在第 1 题 + 282 次编辑/5 次运行 + 焦点 84/h + 同伴对照 + 可照读建议"。
- 做法：坐次末 token 输出离散时间 hazard → 累积生存 S = ∏(1−h_k)；段级 risk 由注意力池化 + hazard 累积两路给出。

### 3.4 训练目标

```
L = L_surv + L_part + λ·L_peer
L_surv = −[ y·log(1−S) + (1−y)·log S ],  S = ∏_k (1 − h_k)
L_part = BCEWithLogits(段级 logit, y, pos_weight = 7.41)   # 258/2171 正例
L_peer = 同段内成对 softplus(−(r_i − r_j))，仅取 peer_z_submit 差 < −0.5 的对
```

### 3.5 与 CS1-SHR 的关系

**不是替代，是升级**：CS2-SPC 负责"段内早警 + 卡点定位"（坐次级），CS1-SHR 的阶段级通道保留，两者在**概率空间 late fusion**（CS1-SHR 已验证融合在 k=1 早警时有效：0.7359 vs 扁平 0.7126）。若 CS2-SPC 在阶段级不过线，则退化为**纯诊断通道**，论文叙事仍然成立（"从负结果到方法"闭环）。

### 3.6 消融设计（本次实跑）

| 配置 | 组件 | 回答的问题 |
|---|---|---|
| `base` | 因果 Transformer + 上下文 | 纯深度在坐次级能否打过 flat RF？ |
| `film` | + 进度 FiLM | 条件化调制有没有增益？ |
| `peer` | + 同伴对比损失 | 归纳偏置有没有增益？ |
| `film_peer` | 全部 | 上限在哪？ |

对照基线（同一脚本、同一协议复现）：RF 坐下第 1 次 / 第 2 次 / 整段。

### 3.7 验收线

- 坐次级（K=1）part 内 pooled **≥ 0.8684**（本次 RF 复现值）才算打平，**> 0.88** 才算有增量；
- 整段 pooled **≥ 0.9228**（本次 RF 复现值）/ 论文口径 0.9258；
- top5% 精确率不低于 RF（坐下级 0.667 / 整段 0.833）；
- **任何增益必须配对 bootstrap 2000 次报告 95% CI 与 P(Δ≤0)**，Δ≤0.001 一律判为噪声；
- **必须补 LOPO**（连续进度调制是否也破坏跨 part 泛化）。

## 4 · 实测结果（本次实跑，246 `/home/ubuntu/studentrisk_stage/results/cs2_spc/`）

### 4.1 协议
按学生分组 5 折 × 3 seeds（42/123/777）；peer 统计量只用训练折；主指标 part 内 pooled AUC；
截断口径与 IPSD / 坐下级实验完全一致（同一脚本重建坐次与截断聚合）。

### 4.2 基线复现（验证协议没跑偏）

| 基线 | 本次复现 | 已发表值 |
|---|---:|---:|
| RF 坐下第 1 次 | 0.8684 | 0.8665 |
| RF 坐下第 2 次 | 0.7969 | 0.7981 |
| RF 坐下第 3 次 | 0.7829 | 0.7942 |
| RF 整段 | 0.9228 | 0.9258 |

### 4.3 CS2-SPC 消融（part 内 pooled AUC / 整段 top5% 精确率）

| 配置 | 坐次级 K=1 | 坐次级 K=2 | 整段 | 整段 top5% |
|---|---:|---:|---:|---:|
| **RF（flat 31 维）** | **0.8684** | **0.7969** | **0.9228** | **0.833** |
| base（纯因果 Transformer） | 0.7912 | 0.7063 | 0.8901 | 0.787 |
| + 进度 FiLM | 0.7840 | 0.7134 | 0.8833 | 0.769 |
| + 同伴成对对比损失 | 0.7963 | 0.6932 | 0.8876 | **0.824** |
| + 两者 | 0.7854 | 0.7018 | **0.8922** | 0.769 |

### 4.4 三条读数（负面但有价值的负面）

1. **深度模型在所有观察深度上都低于 flat RF**（−0.03 ~ −0.08），但**证据越多差距越小**（K=1 −0.077 → 整段 −0.031）
   → 瓶颈是**样本量/证据量**（258 个正例），不是归纳偏置。
2. **同伴对比损失对"名单质量"比对 AUC 更有效**：整段 top5% 精确率 0.787 → **0.824**（接近 RF 的 0.833）；K=1 0.528 → 0.574。
   产品真正要的是"名单里 10 个有 8 个真有问题"，所以这条比 AUC 更有产品意义。
3. **进度 FiLM 没有增益**（甚至略负）→ 如实记为负结果，从 CS2-FWD 的必需组件降级为**可选**。

### 4.5 结论

- **判别线上"再加容量"这条路在 CS1 上封死**（与 6 个候选模型族全部 ≤ RF、Mamba 系 −0.1302 一致）。
- 因此新模型必须**换任务形式**：CS2-FWD（段内"中途停下"早警）。
- CS2-SPC 的设计仍可作论文 §4 方法节，但**不得进主表**。

### 4.6 诊断实验：`mlp_ctx`（同一 31 维上下文、纯 MLP、无 token 序列）

| 模型 | 坐次级 K=1 | 整段 |
|---|---:|---:|
| RF（flat 31 维） | **0.8684** | **0.9228** |
| CS2-SPC base（因果 Transformer + token 序列） | 0.7912 | 0.8901 |
| `mlp_ctx`（同一上下文、纯 MLP、无序列） | 0.7702 | 0.8398 |

**读数（把"深度模型为什么不行"定位清楚）**：
- MLP < Transformer < RF —— **token 序列确实有价值**（+0.021 / +0.050）：flat 聚合丢掉的段内时序信息，因果 Transformer 能捞回来 ⇒ "段内细粒度监控"这条路在模型侧成立；
- 但**树仍然最强** ⇒ 深度模型落后的原因不是"序列没用"，而是**样本量**（2171 行 / 258 正例）在表格任务上不足以让深度模型压过 GBDT 的归纳偏置 —— 这是一般规律，不是没调好。

### 4.7 CS2-FWD（段内"中途停下"早警，新任务形式）

- 标签：y = 该 (生,段) 是否会**段内中途停下**；正例 **201 / 2171（基准率 9.3%）** —— 落在可学区间（对照：习题级停点定位 0.58% 不可学）；
- 设计：习题 token 的因果 Transformer，段内任意观察点输出风险；对照 = 同截断口径的 flat 31 维 RF；
- ⚠️ **诚实边界**：本实验的上下文仍含 SELF（自参照，源自本人**此前各段**的完整聚合），因此段级 pooled AUC 有一部分与"预测最终是否掉队"重叠；**纯段内版本（剔除 SELF）才是干净的"段内早警"**，是下一步要补的口径；
- 实测（观察前 1 道题，配对 bootstrap 2000 次，Δ ＝ RF − 深度）：
  RF flat **0.9129**（top5% 0.657）｜CS2-FWD base 0.8213（Δ **+0.0916**，95% CI [+0.0598, +0.1234]，P(Δ≤0)=0.000）｜CS2-FWD +同伴对比 **0.8427**（Δ **+0.0702**，CI [+0.0411, +0.0998]，P=0.000）
  → **换任务形式后深度模型仍然显著落后**（P(Δ≤0)=0.000），但同伴对比损失把差距从 0.092 拉回 0.070；
- 观察前 3 题：RF flat **0.9733**（top5% 0.778 / top1% 0.905）—— RF 随证据增加迅速饱和，进一步说明该任务（段级标签 + 跨段上下文）本质仍由"谁最终会掉队"驱动；
- 其余观察深度（3/10/全部）的深度模型结果：重跑中（`results/cs2_fwd2/`）。

### 4.8 CS2-D（段内卡点诊断）—— **深度模型唯一明确获胜的地方**

**任务**：对每个含停点的 (生,段)，给出该段内每道题一个分数，目标是**把停点题排到第一**。
**防作弊**：停点按定义就是该段最后一个 token，因此**屏蔽全部位置类特征**（题序进度、坐次内位置、坐次号、坐次末标记），模型只能靠行为本身判断"这一题像卡点"。
**训练**：token 级 BCE（pos_weight=30），按学生分组 5 折 × 3 seeds；token 特征 = 22 维行为 + 7 维 **token 级同伴 z**（同一 part、同一题号、跨学生中位/MAD，训练折统计量）。

| 方法 | top1 命中停点 | top3 | MRR |
|---|---:|---:|---:|
| 启发式：最大事件数 | 0.259 | 0.547 | 0.451 |
| 启发式：最大编辑数 | 0.289 | 0.542 | 0.465 |
| **启发式：最大焦点 churn** | **0.333** | 0.527 | 0.474 |
| 启发式：最大粘贴量 | 0.204 | 0.428 | 0.372 |
| 启发式：组合规则 | 0.144 | 0.338 | 0.314 |
| **CS2-D（深度模型，位置特征已屏蔽）** | **0.607** | **0.806** | **0.722** |

（n = 201 个含停点的 (生,段)）

→ **top1 0.607 vs 最好启发式 0.333（相对 +82%），MRR 0.722 vs 0.474（+52%）**。
含义：现周报里手写的"编辑多/运行少/焦点 churn"启发式规则可以被学出来并且显著更强；且因位置特征被屏蔽，**这不是靠"停点在最后"作弊**。

### 4.9 三组实验的统一结论

| 任务类型 | 深度模型 | 对照 | 结论 |
|---|---|---|---|
| 判别（段级"最终掉队"标签）CS2-SPC | 0.79–0.89 | RF 0.87–0.92 | **深度输 0.03~0.08** |
| 判别（段级"中途停下"标签）CS2-FWD | 0.82–0.84 | RF 0.91–0.97 | **深度输 0.07~0.13**（换任务形式也没救回来） |
| 诊断（段内停点题识别）CS2-D | **0.607 / MRR 0.722** | 启发式 0.333 / 0.474 | **深度赢 1.8×** |

→ **判别线上深度模型在 CS1 上没有出路（两个任务形式都试过），诊断线上深度模型有明确优势。**
→ 因此新的深度学习模型应当是 **CS2-D（诊断型）**，而不是任何以"谁会掉队"为目标的判别模型。

## 5 · 风险与边界（先说清，不吹）

1. **样本量小**：258 个正例、2171 行、44,764 个习题 token。深度模型参数量必须压住（本原型 d=64/2 层），否则过拟合；已用 dropout 0.1 + weight decay 1e-4 + 早停式固定 epochs。
2. **提交质量污染真实存在**：570/2171 行（26.3%）命中 Q1/Q2/Q3，260 名学生。flat 模型上"训练含污染 vs 训练干净"Δ = −0.0052（不损害判别力），但**深度模型对此尚未验证** → CS2 必须用同样的干净集对照跑一遍。
3. **LOPO 未验证**：本轮只做了按学生分组 5 折；FiLM 用连续进度理论上可跨 part 泛化，但**必须实测**，否则不能进论文主表。
4. **外部数据集验证仍是唯一最高优先级缺口**（附录 B）：只有 CS1 一个来源，任何"适用于 CS1 的新模型"主张都缺跨数据集证据。这一条不因新模型而改变。
5. **停止条件**：若 CS2-SPC 在坐次级与整段两条线上都不过线（Δ≤0 且 P(Δ≤0) 不显著），则**论文不再提新架构**，改为"新任务形式 + 严谨评估 + 可执行干预系统"叙事（这正是 §7.6 已写好的主线）。
