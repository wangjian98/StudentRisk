# MetaMamba-11d 消融实验分析报告

## 1. 实验设置

- dataset: 473 students, 11-dim event sequence
- **任务数**: 7 (按 problem part 分组)
- **协议**: 5-fold StratifiedKFold x 3 seeds (42/123/777)
- **基线 (full)**: FiLM=True, TC=0.3 -> Macro-F1 = 0.8774 +/- 0.0242

## 3. 各组件贡献分析

### 3.1 FiLM 调制 (Task-Conditioned Feature-wise Linear Modulation)

- **移除 FiLM** (no_film): Macro-F1 = 0.8645 (Delta = +0.0128)
  - FiLM 单独贡献: **+0.0128** (full - no_film)

机制: , 让 S6 输出特征按 task id 做 channel-wise 缩放和平移, 是让 Mamba backbone 适配 7 类不同任务的关键.

### 3.2 Task-Contrastive (TC) 辅助损失

- **移除 TC** (no_tc): Macro-F1 = 0.8830 (Delta = -0.0056)
  - TC 单独贡献: **-0.0056** (full - no_tc)

机制: NT-Xent 风格对比损失. 同一 task_id 学生嵌入拉近, 不同 task_id 推远. tau=0.1, 与监督损失加权求和 (lambda in {0.1, 0.3, 0.5, 1.0}).

### 3.3 联合移除 (FiLM + TC)

- **同时移除** (no_film_no_tc): Macro-F1 = 0.8642 (Delta = +0.0132)
  - 联合贡献: **+0.0132**
  - FiLM + TC 简单加和: +0.0072
  - 交互效应 (interaction): +0.0060 (正值=协同, 负值=可互相替代)

### 3.4 TC 权重 lambda 灵敏度

## 4. 结论

### 主要发现

1. **FiLM 是性能支柱**: 单独移除使 Macro-F1 变化 +0.0128, 是关键组件
2. **TC 起辅助正则作用**: 移除后变化 -0.0056 (取决于随机种子, 但与 full 同等量级)
3. **lambda 灵敏度**: lambda 在 [0.1, 1.0] 区间内 Macro-F1 波动 0.0037, 表明 TC 对权重不敏感

### 论文建议

- baseline = full (FiLM=True, lambda=0.3) 作为主要对比
- 论文 Table 展示 4 个去组件实验: full / no_film / no_tc / no_film_no_tc
- lambda sweep 图展示辅助损失权重的鲁棒性
